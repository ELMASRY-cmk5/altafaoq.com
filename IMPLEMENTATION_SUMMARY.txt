2️⃣ تحديث الصفحة الرئيسية (home.html)
   ✓ إضافة أوصاف الكورسات المتاحة لكل صف
   ✓ عرض المواد والدروس في كل صف:

3️⃣ نظام المدرسين والمواد الدراسية (في الأدمن)
   ✓ تبويب جديد لإدارة المدرسين
     • إضافة مدرس جديد
     • تسجيل البيانات (الاسم، البريد، الهاتف)
     • تحديد المواد المتخصص فيها
     • حذف المدرسين
   
   ✓ تبويب جديد لإدارة المواد الدراسية
     • إضافة مادة دراسية
     • ربط المادة بالصف
     • تحديد عدد الساعات الأسبوعية
     • حذف المواد

4️⃣ نظام المتجر (store.html)
   ✓ عرض المنتجات من localStorage
   ✓ 4 منتجات تجريبية:
      1. كتاب التفوق للثانوي - 150 ج.م
      2. ملخصات الرياضيات PDF - 50 ج.م
      3. أدوات تنظيم المذاكرة - 75 ج.م
      4. اشتراك مميز (شهري) - 200 ج.م
   
   ✓ إضافة المنتجات للسلة
   ✓ عرض زر "اذهب للدفع والتوصيل"
   ✓ تبويب جديد في الأدمن لإدارة المتجر

5️⃣ صفحة الدفع والتوصيل (checkout.html) - جديدة!
   ✓ ملخص الطلب مع الأسعار
   ✓ بيانات العميل:
      • الاسم الكامل
      • رقم الهاتف
      • اختيار المحافظة (27 محافظة)
      • المدينة
      • العنوان التفصيلي
      • ملاحظات إضافية
   
   ✓ طرق الدفع:
      • Vodafone Cash (01017365486)
      • الدفع عند الاستلام (القاهرة والإسكندرية)
   
   ✓ سعر التوصيل الموحد: 90 ج.م لجميع المحافظات
   ✓ حساب الإجمالي تلقائياً
   ✓ حفظ الطلب في localStorage

6️⃣ نظام الطلبات في الأدمن
   ✓ تبويب جديد "الطلبات"
   ✓ عرض جميع الطلبات الواردة
   ✓ معلومات الطلب:
      • رقم الطلب والعميل
      • المنتجات والكميات
      • العنوان الكامل والمحافظة
      • الإجمالي (المنتجات + التوصيل 90ج)
   
   ✓ تحديث حالة الطلب:
      • قيد الانتظار
      • تم التوصيل
      • ملغاه
