## 📖 نظرة عامة

**منصة التفوق** هي منصة تعليمية حديثة متخصصة لطلاب المرحلة الثانوية، تجمع بين التكنولوجيا المعاصرة والتصميم الفرعوني المستوحى من الحضارة المصرية العريقة.

### ✨ المميزات الرئيسية

- 🎯 **نظام كورسات متقدم**: إضافة وإدارة الكورسات بسهولة
- 💰 **نظام دفع آمن**: Vodafone Cash مع التحقق التلقائي
- 👥 **إدارة طلاب**: قبول/رفض طلبات التسجيل
- 🎨 **تصميم فرعوني**: ألوان ذهبية وأزرق عميق مع تأثيرات احترافية
- 🌙 **وضع ليلي كامل**: دعم الوضع الليلي على جميع الصفحات
- 📱 **متجاوب تماماً**: يعمل على جميع الأجهزة

---

## 🚀 البدء السريع

### للطلاب
1. اذهب إلى [`/home.html`](home.html)
2. انقر على الصف الدراسي الذي تختاره
3. اختر الكورسات المتاحة واشترك فيها
4. ابدأ رحلتك التعليمية!

### للمديرين
1. اذهب إلى [`/admin.html`](admin.html)
2. انقر "تهيئة مدير تجريبي" (المرة الأولى)
3. سجل دخول:
   - **المستخدم**: `admin`
   - **كلمة المرور**: `admin123`
4. أدر الكورسات والطلاب والدفعيات

## 🎯 نظام الكورسات

### ميزات الكورسات
✅ عرض الكورسات المشترك بها منفصلة عن المتاحة  
✅ معلومات كاملة عن كل كورس (السعر، الدروس، الوصف)  
✅ اشتراك سريع وسهل  
✅ تتبع حالة الاشتراك  

### إدارة الكورسات (للمديرين)
✅ إضافة كورسات جديدة  
✅ تعديل الكورسات الموجودة  
✅ حذف الكورسات  
✅ إدارة الأسعار والدروس  

---

## 🔒 نظام الأمان والمصادقة

### أنواع المستخدمين
- **طالب**: يشترك في الكورسات ويتابع تقدمه
- **مدير**: يدير الكورسات والطلاب والدفعيات

### تدفق التسجيل
1. الطالب يملأ نموذج التسجيل
2. الطلب ينتظر موافقة الإدارة
3. المدير يوافق أو يرفض
4. الموافقة = حساب نشط ومباشر

## 💾 التخزين والبيانات

جميع البيانات تُخزن محلياً في `localStorage`:

```javascript
tf_users          → قائمة المستخدمين
tf_current        → المستخدم الحالي
tf_courses        → قائمة الكورسات
tf_enrollments    → الاشتراكات
tf_registrations  → طلبات التسجيل
tf_payments       → عمليات الدفع
tf_theme          → الوضع الحالي
```
